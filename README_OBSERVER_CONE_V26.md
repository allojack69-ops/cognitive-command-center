# Observer Adaptive Future Cone v2.6

Replaces the static Closed-Candle Cycle cards with a live interactive SVG.

- current X-state at the apex
- H5/H15/H30/H60 future slices
- slice strength reflects tradeability
- Strategy / GSR1 / EH1 / CGE1 / AAL1 vectors
- BUY appears on the right, SELL on the left
- ERL1 decision gate at the base
- animated Outcome → Memory → Next State feedback loop
- state-change pulse when Xn advances
- tap horizons, vectors, apex, gate, or memory for details
- ALL / HORIZONS / SIGNALS / LEARNING LOOP modes

No DB migration. Uses the existing 3-second Observer status refresh.
